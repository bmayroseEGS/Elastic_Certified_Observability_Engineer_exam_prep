# Dashboards & Visualizations

Observability dashboard and visualization exercises for the Elastic Certified Observability Engineer exam.

## Topics

- Building dashboards in Kibana
- Visualization types (TSVB, Lens, Vega, Maps)
- Logs, metrics, and APM panels
- ES|QL and KQL for querying data
- Dashboard drilldowns and filters
- Annotation and event overlays
- Sharing and exporting dashboards
- SLO dashboards and service health views
