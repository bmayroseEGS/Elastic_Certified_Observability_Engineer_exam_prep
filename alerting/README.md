# Alerting

Alerting rules and configuration exercises for the Elastic Certified Observability Engineer exam.

## Topics

- Creating and managing alerting rules
- Observability alert types (metric threshold, log threshold, anomaly, uptime, APM)
- Action connectors (email, Slack, PagerDuty, webhook, etc.)
- Alert grouping and suppression
- Maintenance windows
- Alert status and lifecycle management
- Rule snoozing and muting
- SLOs and burn rate alerts
