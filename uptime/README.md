# Uptime / Synthetics

Uptime and synthetic monitoring exercises for the Elastic Certified Observability Engineer exam.

## Topics

- Configuring Heartbeat for lightweight uptime monitors
- HTTP, TCP, and ICMP monitor types
- Synthetic monitoring with Elastic Synthetics
- Writing and managing browser-based synthetic tests
- Private locations and Elastic Agent-based monitors
- Monitor status and availability tracking
- TLS certificate monitoring
- Alerting on uptime and availability changes
