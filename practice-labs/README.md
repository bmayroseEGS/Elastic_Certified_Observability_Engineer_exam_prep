# Practice Labs

Hands-on practice scenarios for the Elastic Certified Observability Engineer exam.

## Labs

- **Lab 01** - Deploy Elastic Agent and collect system logs and metrics
- **Lab 02** - Parse and enrich logs with ingest pipelines
- **Lab 03** - Set up APM with a sample application
- **Lab 04** - Configure synthetic monitors for HTTP and browser checks
- **Lab 05** - Create metric threshold and log threshold alerts
- **Lab 06** - Build an observability dashboard with Lens and TSVB
- **Lab 07** - Configure Fleet and manage agents at scale
- **Lab 08** - Set up SLOs and burn rate alerts
- **Lab 09** - Correlate logs, metrics, and traces for incident investigation
- **Lab 10** - End-to-end observability scenario

## Tips

- Practice in a local Elastic Stack or Elastic Cloud environment
- Use the [Elastic documentation](https://www.elastic.co/guide/en/observability/current/index.html) as a reference
- Time yourself to simulate exam conditions
