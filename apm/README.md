# APM

Application Performance Monitoring setup and configuration exercises for the Elastic Certified Observability Engineer exam.

## Topics

- Installing and configuring APM agents (Java, Node.js, Python, .NET, Go, etc.)
- APM Server setup and integration with Elastic Agent
- Distributed tracing and trace correlation
- Transaction and span analysis
- Service maps and dependency visualization
- Error tracking and grouping
- Custom instrumentation and context
- APM latency, throughput, and error rate analysis
