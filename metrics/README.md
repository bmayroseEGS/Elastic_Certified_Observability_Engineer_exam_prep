# Metrics

Infrastructure and application metrics monitoring exercises for the Elastic Certified Observability Engineer exam.

## Topics

- Collecting system and host metrics with Elastic Agent
- Infrastructure UI and inventory views
- Metrics Explorer for ad-hoc analysis
- Custom metrics and metric thresholds
- Cloud provider metrics (AWS, GCP, Azure)
- Kubernetes and container metrics
- Metric anomaly detection
- Creating metric-based alerts
